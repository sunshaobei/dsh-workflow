# MCode 工作流移植规格

基准：<本地 MCode 检出> 当前检出源码，截图为视觉参考。替换工作流插件；原插件备份 <本地备份目录>，用户脚本和历史保留。

## 状态与接口

MCode 引擎拥有运行、阶段、节点、schema 校验和重放；dsh driver 负责真实子会话、取消、产物持久化。Host registry 拥有全局/项目脚本及参数，使用 MCode YAML frontmatter，兼容旧 @arg。客户端仅保存表单、展开态，所有视图订阅同一投影。使用正式插件插槽接入，不修改宿主 DOM。

## 验收

- 自动化/工作流标题，全局与打开项目分组，卡片详情/运行/修订/路径/移动/删除，加载/空/错误态。
- 参数支持 string/number/boolean/json、required/default；运行关联正确工作目录与会话。
- 时间线站宽168、间距24、药丸高32、间距6；运行橙色、完成绿色、失败红色、未来空环。
- 对话工具卡/完成卡、右侧竖向阶段、子会话、产物预览关联同一运行。
- 配置并发、停止取消、恢复重放、保存、再次运行、真实产物下载。
- 完成卡四项统计；无证据数字显示 —。错误不隐藏，卸载释放订阅。

## 验证

编译；元数据/参数/投影/执行取消测试；浏览器检查表单、菜单、卡片、右侧阶段、产物及窄屏；核对安装版本正式 Host 插槽。外部模型调用需实际运行验证，不伪造结果。
